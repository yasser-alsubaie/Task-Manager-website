Academic Task and Project Management System

مشروع نظام إدارة المهام والمشاريع الأكاديمية - مقرر الدبلوم.

 فريق العمل (Team Members):
* عبدالإله فيصل القاسم (التحليل، التقرير، والعرض)
* ياسر فواز السبيعي (قاعدة البيانات والـ SQL)
* نواف ابراهيم مرير (الواجهات والبرمجة)
 
 محتويات المشروع (Project Files):
* `ERD_Diagram.png`: مخطط العلاقات للكيانات (ERD Diagram).
*  `project.sql`: ملف قاعدة البيانات الأساسي (MySQL).
* `Use Case diagram.png`: مخطط حالات الاستخدام  (Use Case diagram).
*  `Gantt_Chart.xlsx ` and `Gantt_Chart.xlsx.pdf ` : مخطط جانت (Gantt Chart).
*  `Activity Diagram.draweio.png ` and ` Context Diagram.draweio.png` : مخطط السياق (Context Diagram) و  (Activity Diagram) مخطط الأنشطة
*  `login.php ` صفحة تسجيل الدخول
*  `logout.php ` صفحة تسجيل الخروج من الحساب
*  `dashboard.php ` الصفحة الرئيسية
*  `db.php ` ربط قاعدة البيانات بالموقع
*  `register.php ` صفحة إنشاء الحساب
*  `projects.php ` صفحة ادارة المشاريع 
*  `tasks.php ` صفحة انشاء المهام
*  `update.php ` صفحة تحديث المشاريع
*  `auth.php ` صفحة التحقق
*  `style.css ` تصميم الموقع

 نبذة عن المشروع:
هذا النظام مخصص لإدارة المشاريع والمهام الأكاديمية للمستخدمين، بحيث يتيح إنشاء المشاريع وتتبع مهامها وحالتها بكل سهولة.
